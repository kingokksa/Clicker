# 外部接口（MCP + REST）

Clicker 连点器对外暴露的能力接口。所有能力共用一份注册表，同时以 **MCP**（给 AI 客户端）、**REST** 与 **OpenAPI 3.1** 三种形式提供。

共 **53** 个能力，分为 8 组：`system`、`clicker`、`input`、`macro`、`vision`、`schedule`、`profile`、`script`。

## 快速开始

1. 打开软件 → 侧边栏 **外部接口** → 打开「启用服务」。
2. 复制页面上的**访问令牌**；如需换新令牌点「重新生成」。
3. 在页面「接入地址」里拿到局域网地址，例如 `http://192.168.1.10:9876`。

> 服务绑定 `0.0.0.0`，同一局域网的任何设备都能访问，**令牌是唯一防线**，请勿泄露，也不要把端口暴露到公网。

### 端点一览

| 端点 | 方法 | 鉴权 | 说明 |
|---|---|---|---|
| `/health` | GET | 否 | 存活检查，返回能力数量与版本 |
| `/api/v1/capabilities` | GET | 是 | 全部能力及其参数 schema |
| `/api/v1/<能力名>` | GET / POST | 是 | 调用某个能力 |
| `/openapi.json` | GET | 是 | OpenAPI 3.1 文档 |
| `/mcp` | POST | 是 | MCP JSON-RPC 2.0 端点 |

令牌可放在三处任意一处：`Authorization: Bearer <令牌>`、`Authorization: <令牌>`、`X-Api-Token: <令牌>`，或查询参数 `?token=<令牌>`。

## MCP 接入

把下面这段加进 AI 客户端的 MCP 配置（`url` 与令牌换成你自己的）：

```json
{
  "mcpServers": {
    "clicker": {
      "type": "http",
      "url": "http://192.168.1.10:9876/mcp",
      "headers": {
        "Authorization": "Bearer <令牌>"
      }
    }
  }
}
```

支持的 MCP 方法：`initialize`、`ping`、`tools/list`、`tools/call`、`resources/list`、`prompts/list`。协议版本 `2025-06-18`。

调用某个能力（`tools/call`）：

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "clicker_get_config",
    "arguments": {}
  }
}
```

响应里 `result.structuredContent` 是能力的原始返回值，`result.content[0].text` 是它的 JSON 文本；失败时 `result.isError` 为 `true`，错误信息（含修复提示）在 `result.content[0].text` 里。

## REST 接入

```bash
# 查看全部能力
curl -H "Authorization: Bearer <令牌>" \
  http://192.168.1.10:9876/api/v1/capabilities

# 调用能力（POST + JSON 对象）
curl -X POST -H "Authorization: Bearer <令牌>" \
  -H "Content-Type: application/json" \
  -d '{"x": 100, "y": 200}' \
  http://192.168.1.10:9876/api/v1/clicker_click_at
```

GET 调用时参数直接写在查询串上（`/api/v1/vision_get_pixel?x=10&y=20`），字符串形式的数字与布尔会自动转换。

成功响应：`{"ok": true, "action": "<能力名>", "result": {...}}`。
失败响应：`{"ok": false, "action": "<能力名>", "error": {"code", "message", "hint"}}`。

| HTTP | error.code | 含义 |
|---|---|---|
| 400 | `invalid_argument` | 参数缺失或类型不对（`hint` 里有示例） |
| 401 | `unauthorized` | 缺少或无效的令牌 |
| 404 | `not_found` | 能力或路径不存在 |
| 405 | `method_not_allowed` | `/mcp` 只接受 POST |
| 409 | `conflict` | 当前状态不允许该操作 |
| 500 | `internal` | 内部错误 |
| 501 | `unsupported` | 当前平台不支持 |

## 能力清单

### system（2 个）

#### `system_capabilities`

列出全部可用能力及其参数

返回本接口支持的所有能力、分组、说明与 JSON Schema。首次接入时先调用它，即可知道能做什么、参数怎么传。

> 只读能力，不改变任何状态。

无参数。

#### `system_status`

获取软件整体运行状态

返回连点器、宏、脚本的运行状态、点击计数、平台与屏幕尺寸。用于判断当前是否正在连点或录制，避免重复启动。

> 只读能力，不改变任何状态。

无参数。

### clicker（6 个）

#### `clicker_start`

开始自动连点

按当前配置开始自动连点。需要 config.autoClickEnabled 为 true，否则返回错误；可先调用 clicker_set_config 打开。

无参数。

#### `clicker_stop`

停止自动连点

停止正在进行的自动连点。未运行时调用也返回成功。

无参数。

#### `clicker_toggle`

切换连点开关

正在连点则停止，否则开始。等价于手动点击主按钮。

无参数。

#### `clicker_get_config`

读取连点配置

返回完整配置对象，字段名与 clicker_set_config 接受的键一致。

> 只读能力，不改变任何状态。

无参数。

#### `clicker_set_config`

修改连点配置

局部更新配置：只传要改的字段，未传的保持不变。可传任意 ClickerConfig 字段（如 intervalMs、clickMode、clickType、positionMode、fixedX、fixedY、repeatMode、repeatCount、humanLikeEnabled、randomOffsetEnabled、autoClickEnabled 等）。枚举字段用名称字符串（如 "mouse"、"single"、"fixed"）。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `patch` | object | 是 | 要修改的字段集合，键为配置字段名 |

#### `clicker_click_at`

在指定坐标点击一次

不启动连点循环，立即在 (x, y) 执行一次鼠标点击。适合"点一下某个按钮"这类一次性动作。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `x` | integer | 是 | 屏幕 X 坐标 |
| `y` | integer | 是 | 屏幕 Y 坐标 |
| `button` | string | 否 | 鼠标按键；可选值：`left` / `right` / `middle`；默认 `"left"` |
| `doubleClick` | boolean | 否 | 是否双击；默认 `false` |

### input（5 个）

#### `input_move`

移动鼠标到指定坐标

立即把鼠标光标移动到 (x, y)，不产生点击。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `x` | integer | 是 | 屏幕 X 坐标 |
| `y` | integer | 是 | 屏幕 Y 坐标 |

#### `input_drag`

拖拽鼠标

从起点按住拖到终点后松开，用于拖动窗口、滑块、选中文本等。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `startX` | integer | 是 | 起点 X |
| `startY` | integer | 是 | 起点 Y |
| `endX` | integer | 是 | 终点 X |
| `endY` | integer | 是 | 终点 Y |
| `durationMs` | integer | 否 | 拖拽耗时（毫秒），越大越平滑；默认 `300`；最小 0；最大 10000 |
| `button` | string | 否 | 鼠标按键；可选值：`left` / `right` / `middle`；默认 `"left"` |

#### `input_scroll`

滚动鼠标滚轮

dx 为水平滚动量，dy 为垂直滚动量。正值 dy 通常表示向上滚动。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `dx` | number | 否 | 水平滚动量；默认 `0` |
| `dy` | number | 否 | 垂直滚动量；默认 `0` |

#### `input_key`

按下或松开一个按键

key 用按键名，如 "a"、"enter"、"f5"、"ctrl"、"shift"、"esc"、"tab"、"space"、"up"、"down"、"left"、"right"。默认按下并立即松开（一次完整按键）。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `key` | string | 是 | 按键名 |
| `hold` | boolean | 否 | 是否按住不放（true 则不自动松开）；默认 `false` |

#### `input_type`

输入一段文本

逐字符输入文本，适合填写表单、搜索框。如需中文等非 ASCII 字符，请确认目标程序支持。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `text` | string | 是 | 要输入的文本 |
| `delayMs` | integer | 否 | 每个字符间隔（毫秒）；默认 `30`；最小 0；最大 2000 |

### macro（12 个）

#### `macro_list`

列出所有宏

返回全部宏的 id、名称、事件数、总时长、重复次数、速度与启用状态。

> 只读能力，不改变任何状态。

无参数。

#### `macro_get`

读取单个宏的完整定义

按 id 返回宏的全部事件序列，可用于理解或复制已有宏。

> 只读能力，不改变任何状态。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | string | 是 | 宏 id |

#### `macro_create`

创建一个新宏

用事件序列直接创建宏，无需手动录制。events 每项形如 {"type":"click","timestampMs":0,"x":100,"y":200}；type 可取 mouseDown/mouseUp/click/keyPress/keyRelease/scroll/wait/drag/swipe。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `name` | string | 是 | 宏名称 |
| `events` | array<object> | 是 | 事件数组 |
| `repeatCount` | integer | 否 | 重复次数，0 表示无限；默认 `1`；最小 0 |
| `speed` | number | 否 | 播放倍速；默认 `1.0`；最小 0.1；最大 10 |

#### `macro_update`

修改宏的属性

按 id 修改宏的名称、重复次数、速度、启用状态或事件序列。只传要改的字段。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | string | 是 | 宏 id |
| `patch` | object | 是 | 要修改的字段，可含 name/repeatCount/speed/enabled/events |

#### `macro_rename`

重命名宏

按 id 修改宏名称。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | string | 是 | 宏 id |
| `name` | string | 是 | 新名称 |

#### `macro_delete`

删除宏

按 id 永久删除一个宏。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | string | 是 | 宏 id |

#### `macro_play`

播放宏

按 id 播放宏。若已在播放中会先停止当前播放。播放是异步的，本调用立即返回。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | string | 是 | 宏 id |
| `wait` | boolean | 否 | 是否等待播放结束再返回；默认 `false` |

#### `macro_stop`

停止宏播放

停止当前正在播放的宏。

无参数。

#### `macro_record_start`

开始录制宏

开始记录鼠标与键盘操作。录制期间请正常操作，结束后调用 macro_record_stop 保存。

无参数。

#### `macro_record_stop`

停止录制并保存宏

结束录制并把记录的操作保存为一个新宏，返回新宏的 id。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `name` | string | 否 | 宏名称；默认 `"录制的宏"` |

#### `macro_record_cancel`

取消录制

放弃当前录制内容，不保存。

无参数。

#### `macro_record_pause`

暂停录制

暂停录制，暂停期间的操作不会被记录。再次调用可继续。

无参数。

### vision（17 个）

#### `vision_ocr_engines`

列出可用的文字识别引擎

返回所有 OCR 引擎的 id、名称、是否可用与当前选中项。用 vision_set_ocr_engine 切换。

> 只读能力，不改变任何状态。

无参数。

#### `vision_set_ocr_engine`

切换文字识别引擎

按 id 切换 OCR 引擎，传 auto 恢复默认（Windows OCR）。可用 vision_ocr_engines 查看可选 id。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | string | 否 | 引擎 id，传 auto 恢复默认 |

#### `vision_list_templates`

列出所有图像模板

返回模板库里保存的模板 id、名称与尺寸，供 vision_find_image 按 id 或名称引用。

> 只读能力，不改变任何状态。

无参数。

#### `vision_capture_template`

截取屏幕区域保存为模板

把屏幕上 (x, y) 起 width×height 的区域保存为可复用的图像模板，之后可用 vision_find_image 在屏幕中查找它。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `x` | integer | 是 | 区域左上角 X |
| `y` | integer | 是 | 区域左上角 Y |
| `width` | integer | 是 | 区域宽度；最小 1 |
| `height` | integer | 是 | 区域高度；最小 1 |
| `name` | string | 是 | 模板名称 |
| `threshold` | number | 否 | 匹配阈值 0~1，越高越严格；默认 `0.85`；最小 0；最大 1 |
| `regionX` | integer | 否 | x 的别名 |
| `regionY` | integer | 否 | y 的别名 |
| `regionWidth` | integer | 否 | width 的别名；最小 1 |
| `regionHeight` | integer | 否 | height 的别名；最小 1 |

#### `vision_find_image`

在屏幕中查找图像模板

在指定区域内查找已保存的模板，返回是否找到、匹配位置与中心点坐标（可直接喂给 input_click 或 clicker_click_at）。需要多个匹配用 vision_find_image_all，需要等它出现用 vision_wait_image。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `templateId` | string | 否 | 模板 id（与 templateName 二选一） |
| `templateName` | string | 否 | 模板名称（与 templateId 二选一） |
| `regionX` | integer | 否 | 搜索区域左上角 X，默认整屏 |
| `regionY` | integer | 否 | 搜索区域左上角 Y，默认整屏 |
| `regionWidth` | integer | 否 | 搜索区域宽度，默认整屏 |
| `regionHeight` | integer | 否 | 搜索区域高度，默认整屏 |
| `threshold` | number | 否 | 覆盖模板自带的匹配阈值 0~1；最小 0；最大 1 |
| `scales` | array<number> | 否 | 多尺度搜索的比例列表，如 [1.0, 0.9, 1.1]（0.2~5.0）；省略则只按原尺寸匹配 |
| `x` | integer | 否 | regionX 的别名 |
| `y` | integer | 否 | regionY 的别名 |
| `width` | integer | 否 | regionWidth 的别名 |
| `height` | integer | 否 | regionHeight 的别名 |

| `regionHeight` | integer | 否 | 搜索区域高度，默认整屏 |

| `maxResults` | integer | 否 | 最多返回多少个匹配；默认 `10`；最小 1；最大 200 |
| `scales` | array<number> | 否 | 多尺度搜索的比例列表，如 [1.0, 0.9, 1.1]（0.2~5.0）；省略则只按原尺寸匹配 |

### schedule（4 个）

#### `schedule_list`

列出所有定时任务

返回定时任务的下标、动作、触发方式与下次触发时间。下标用于 schedule_update 与 schedule_remove。

> 只读能力，不改变任何状态。

无参数。

#### `schedule_add`

新增一个定时任务

timing 为 clock 时按每天的 hour:minute 触发；为 countdown 时在 afterMinutes 分钟后触发。action 可取 startClick/stopClick/playMacro/stopMacro。返回新任务的下标。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `action` | string | 是 | 到点执行的动作；可选值：`startClick` / `stopClick` / `playMacro` / `stopMacro`；默认 `"startClick"` |
| `timing` | string | 否 | 触发方式；可选值：`clock` / `countdown`；默认 `"clock"` |
| `repeat` | string | 否 | 重复方式；可选值：`once` / `daily` / `weekly` / `weekdays` / `interval`；默认 `"once"` |
| `weekday` | integer | 否 | 星期 1~7（repeat=weekly 时使用，1 为周一）；默认 `1`；最小 1；最大 7 |
| `intervalMinutes` | integer | 否 | 间隔分钟数（repeat=interval 时使用）；默认 `30`；最小 1；最大 1440 |
| `hour` | integer | 否 | 小时 0~23（timing=clock 时使用）；默认 `8`；最小 0；最大 23 |
| `minute` | integer | 否 | 分钟 0~59（timing=clock 时使用）；默认 `0`；最小 0；最大 59 |
| `afterMinutes` | integer | 否 | 多少分钟后触发（timing=countdown 时使用）；默认 `10`；最小 1；最大 10080 |
| `macroId` | string | 否 | 要播放的宏 id（action=playMacro 时必填） |
| `enabled` | boolean | 否 | 是否立即启用并布防；默认 `true` |

#### `schedule_update`

修改定时任务

按下标修改定时任务。只传要改的字段。改动时间或启用状态后会自动重新布防。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `index` | integer | 是 | 任务下标，从 0 开始；最小 0 |
| `patch` | object | 是 | 要修改的字段，可含 action/timing/repeat/weekday/intervalMinutes/hour/minute/afterMinutes/macroId/enabled |

#### `schedule_remove`

删除定时任务

按下标删除一个定时任务。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `index` | integer | 是 | 任务下标；最小 0 |
